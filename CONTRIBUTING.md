# Contributing

Thank you for your interest in improving this repository.

## Contribution Guidelines

- Keep solutions clear, minimal, and easy to follow
- Prefer descriptive file names based on the problem being solved
- Include a short problem statement or example at the top of each solution file
- Ensure example usage still runs before submitting changes
- Avoid introducing unnecessary dependencies

## Suggested Workflow

1. Add or update a single problem solution
2. Verify the script runs successfully
3. Update `README.md` if you add a new problem file
4. Open a pull request with a concise description of the change
