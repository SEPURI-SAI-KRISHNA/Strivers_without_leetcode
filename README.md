# Strivers Without LeetCode

A growing collection of Python solutions for common data structures and algorithms problems, organized in a lightweight repository for quick reference and practice.

## Overview

This repository is intended to host clean and beginner-friendly implementations of classic coding interview problems inspired by the Striver-style preparation approach.

Current examples include:

- `largest_number.py` - find the largest value in an array
- `lower_bound.py` - find the first index where `arr[i] >= x` using binary search

## Getting Started

### Prerequisites

- Python 3.8 or newer

### Run the examples

```bash
python largest_number.py
python lower_bound.py
```
